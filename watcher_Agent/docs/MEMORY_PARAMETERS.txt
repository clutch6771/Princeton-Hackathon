MEMORY AND PARAMETER REGISTRY (authoritative)
=============================================
Every memory field and configuration parameter of the Judge.
Origin column:  PRD = product requirement   INT = operational interpretation
                ENG = engineering setting chosen here (the PRD gives no number)
Configuration lives in one typed source: judge/config.py (Settings). Names
below are the environment variable names. The model cannot alter any of them.


A. SEMANTIC MEMORY  (shared Store; written by the approval owner, read by Judge)
-------------------------------------------------------------------------------
Location   Store table "store": prefix "<user_id>.memories", key "values.md"
Writer     Guardian / approval owner (owner role).   Reader: Judge (SELECT only)
Lifetime   Until the owner replaces or deletes it. Judge never writes.

Field                 Type            Meaning / validation                  Origin
content               str | [lines]   Canonical Markdown of approved values PRD
revision              int | str       Revision; falls back to sha256 prefix PRD
sha256                hex(64)         Hash of canonical content; verified   PRD
approval.status       str             Must be "approved" to be used         PRD
approval.approved_at  datetime        Approval time                         PRD
lifecycle.status      active|deleted  "deleted" -> unavailable              PRD
Per entry (Markdown)  value id, title, strength, Want more, Want less,
                      Unless, In my words, Evidence, Approved, Status
                      (superseded by Vn | deleted). Wording kept verbatim.  PRD
VALUES_ACCESS_MODE = read_only (constant)                                   PRD
VALUES_REQUIRE_APPROVAL_METADATA  bool, default true                        INT
VALUES_MAX_BYTES  16384 bytes. Over cap -> unavailable; never truncated     ENG
VALUES_STORE_SCHEMA  "public"                                               ENG
A snapshot (revision + sha256) is pinned on every judged reel.


B. STORED EVIDENCE  (schema judge; written by Judge; kept until owner deletes)
-------------------------------------------------------------------------------
judge.reels            PRD record: id, session_id, start, end, thumbnail_url,
                       transcript, on_screen_text, description, features.topics,
                       features.format, features.tone, features.hook,
                       features.emotional_pull, features.is_ad, verdict
                       (aligned|neutral|conflict), confidence [0,1] finite,
                       value_ids, reason                                    PRD
                       Extension: evaluation_status, nullable verdict,
                       owner_id, order_seq, coverage, audio_status,
                       transcript_status, segmentation_status, close_reason,
                       boundary_uncertainty_ms, first_second_observed,
                       values_revision, values_sha256, feedback_example_ids,
                       retrieval_mode, model_id, prompt_version,
                       understanding_attempts, idempotency_key, timings,
                       latency_overrun, error_code                          INT
                       Readers: app, Guardian, Reflector.
judge.reel_thumbnails  one JPEG bytea per judged reel, <= 48 kB             PRD
judge.reel_embeddings  profile_id, model_id, dimension, task_type, status,
                       attempts, error_code                                 PRD/ENG
judge.reel_embedding_vectors  vector(768), keyed by (reel, profile)         ENG
judge.feedback         reel_id, label, score, comment, source. Writer: app
                       via POST /feedback. Score has no defined range.      PRD
Deletion: DELETE /reels/{id}, /sessions/{id}, /data (owner-scoped, cascades).


C. OPERATIONAL STATE  (schema judge; written by Judge)
-------------------------------------------------------------------------------
judge.sessions               lifecycle, last_ingest_at, order cursor, counts
judge.session_events         one "session_completed" row per session
judge.ingest_receipts        idempotency metadata; pruned after 24 h; no media
judge.notification_policy    versioned policy per owner
judge.notification_batches   ordered membership counts and outcome
judge.notification_outbox    stable ids, lease, dispatch, ack, expiry
judge.user_notification_state  last_dispatch_at (cooldown anchor)
public.judge_schema_migrations migration ledger


D. VOLATILE STATE  (RAM only; bounded; released on every exit path)
-------------------------------------------------------------------------------
Safe frame reservoir   first, last, <= 4 thinned frames per open reel
Audio buffer           decoded PCM16 segments with capture timestamps
Candidate intervals    open and closed exposures awaiting final audio
Provider payloads      frames + WAV clip of a queued or running job
Context caches         values snapshot (5 s), feedback examples
Lost on restart; affected reels become lost_on_restart. Never written to
PostgreSQL, files, logs, traces or queues.

F. SECRETS  (environment or secret store only)
-------------------------------------------------------------------------------
DATABASE_URL            runtime role; TLS required in production
MIGRATION_DATABASE_URL  owner role; migrations and seeding only
GEMINI_API_KEY          provider key
Never placed in memory documents, model prompts, logs, fixtures or the repo.
Separate API keys do not by themselves give separate quota pools.
