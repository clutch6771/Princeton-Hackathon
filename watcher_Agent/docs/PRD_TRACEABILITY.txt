Current implementation limits
-------------------------------
The current native JSON path sends one frame + device transcript (partial).
The PRD stream path receives up to 3 selected frames plus assembled AAC audio,
but the native periodic JPEG/AAC uploader and a trusted feed gate remain to
be implemented. Legacy uploads are refused in production. Similar feedback
retrieval is a recent-feedback fallback on the Judge and keyword matching in
the Guardian adapter, not semantic nearest-neighbour retrieval.

Chat route wrapping, value approval UI, Reflector orchestration and device
notification policy remain separate owners. Guardian files were not modified.
The Judge does not call an agent at session completion.

Verification must distinguish synthetic provider tests, real PostgreSQL
repository/role tests, opt-in live Gemini tests and physical-device tests.
No synthetic test result establishes provider quality or device behavior.

Grok is now the default provider. Its audio path requires separate xAI STT
and vision requests; the one-call Gemini PRD path remains optional. See
SAMPLE_EXECUTIONS.txt for actual replay results and opt-in live Grok checks.
